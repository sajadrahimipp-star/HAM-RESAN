# همرسان — پیام‌رسان آنلاین

نسخه اولیه قابل اجرا از پیام‌رسان فارسی با ورود کاربران، گفت‌وگوی خصوصی، گروه، پیام زنده و ارسال فایل.

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر
- دسترسی به ترمینال

## اجرای محلی
1. این پوشه را از حالت ZIP خارج کنید.
2. در همین پوشه اجرا کنید:
   ```bash
   npm install
   ```
3. فایل `.env.example` را به `.env` تغییر نام دهید و مقدار `SESSION_SECRET` را با یک رشته تصادفی طولانی جایگزین کنید.
4. حساب‌ها را بسازید:
   ```bash
   npm run seed
   ```
5. برنامه را اجرا کنید:
   ```bash
   npm start
   ```
6. در مرورگر آدرس `http://localhost:3000` را باز کنید.

## ۲۰ حساب اولیه
نام‌های کاربری: `user01` تا `user20`

رمز عبور اولیه همه حساب‌ها: `Hamresan@`

**هشدار:** این رمزها فقط برای راه‌اندازی و آزمایش‌اند. پیش از دعوت کاربران واقعی، برای هر حساب رمز یکتای قوی تعیین کنید. اطلاعات ورود را عمومی منتشر نکنید.

## امکانات موجود
- ورود و خروج با نشست سمت سرور و هش رمز عبور با bcrypt
- ۲۰ حساب اولیه و یک حساب مدیر (user01)
- گفت‌وگوی خصوصی و ساخت گروه
- ارسال پیام زنده با Socket.IO
- ارسال تصویر، ویدئو و فایل تا سقف پیش‌فرض ۵۰ مگابایت
- ذخیره کاربران، گفتگوها و پیام‌ها در SQLite

## آنلاین‌کردن برای ۲۰ نفر
این پروژه به‌صورت فایل آماده است اما هنوز روی اینترنت میزبانی نشده است. برای استفاده هم‌زمان از دستگاه‌های مختلف:
- روی یک VPS یا سرویس Node.js میزبانی کنید.
- دامنه و HTTPS فعال کنید.
- متغیرهای `SESSION_SECRET` و `NODE_ENV=production` را تنظیم کنید.
- دیسک پایدار برای پوشه‌های `data/` و `uploads/` در نظر بگیرید.
- پورت برنامه را از طریق reverse proxy امن در دسترس قرار دهید.

برای محیط عملیاتی، فایل‌های آپلودی را پشت کنترل دسترسی قرار دهید (در این نسخه مسیر فایل‌ها برای هر دارنده لینک قابل دسترسی است)، بکاپ منظم بگیرید، محدودیت نوع فایل و اسکن بدافزار اضافه کنید و سیاست نگهداری داده تدوین کنید. برای چند سرور هم‌زمان، به ذخیره‌سازی مشترک و آداپتر Socket.IO نیاز است.

## نکته امنیتی
این یک نسخه اولیه کاربردی است، نه سرویس آماده انتشار عمومی. پیش از استفاده واقعی، رمزهای اولیه را عوض کنید، secret قوی بسازید، HTTPS اجباری کنید و دسترسی فایل‌ها را محدود کنید.
